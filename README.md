### How I approach a project

**Understand → Define → Decide → Deliver → Learn**

- **Start with the problem.** Understand the workflow, the people involved, and what a useful outcome looks like.
- **Make the trade-offs explicit.** Agree on priorities, scope boundaries, and the balance between time, cost, and quality.
- **Give the team clarity.** Connect requirements, technical decisions, and acceptance criteria.
- **Close the loop.** Check the delivered result against the original need and use what we learn to guide the next iteration.
